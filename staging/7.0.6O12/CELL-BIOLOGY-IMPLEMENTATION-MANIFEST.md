## Scope and reuse rule

All nine units are shared Foundation/Higher requirements in the cached AQA Trilogy specification. Use six extension bundles in existing sections, 18 genuinely new question records and one recovered existing challenge prompt. No new standalone lesson or duplicated chromosome explanation. Per-unit completeness requires human review of teaching, revision, assessment and feedback; number of questions is not proof of adequacy.
